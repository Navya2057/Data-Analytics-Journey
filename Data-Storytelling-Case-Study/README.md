# Data Storytelling Case Study

## 📌 Project Title
Employee Salary Analysis

## 🎯 Problem Statement
The HR department wanted to understand salary distribution across different departments and identify departments with higher average salaries.

## 📂 Dataset
Sample Employee Dataset

Columns:
- Employee ID
- Name
- Department
- Salary

## 🛠️ Approach
1. Loaded the dataset using Pandas.
2. Cleaned duplicate and missing values.
3. Grouped employees by department.
4. Calculated average salary.
5. Visualized insights using bar charts.

## 📊 Key Insights
- IT department has the highest average salary.
- HR department has the lowest average salary.
- Finance salaries are close to the overall average.
- Salary distribution is uneven across departments.

## 💡 Recommendations
- Review salary structure in HR.
- Maintain competitive salaries in IT.
- Conduct annual salary benchmarking.
- Introduce performance-based incentives.

## 📈 Business Impact
These insights help HR make informed salary decisions, improve employee retention, and optimize compensation planning.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
